# Campaign art

Generated with the built-in Imagegen tool for the requested Gravity Falls adventure. Source outputs are copied unchanged into the repository. These are new fan-game illustrations, not extracted assets from Rumble’s Revenge.

## Saved assets

- `web/assets/fighters/dipper.png` — transparent 4 × 3 sheet, twelve Dipper poses.
- `web/assets/fighters/mabel.png` — transparent 4 × 3 sheet, twelve Mabel poses.
- `web/assets/adventure/map.png` — illustrated map, with clickable level markers supplied by HTML.
- `web/assets/adventure/stages.png` — three equal-height horizontal panoramas: forest, town, mine. Canvas crops the appropriate row and scrolls it with the hero.

Standing frames are aligned from their alpha bounds. Mabel's knockout slightly overlaps the adjacent grid cell; explicit source rectangles in `fighters.js` handle this without modifying the PNG. Original PNG alpha is preserved. The final dojo uses the original MUGEN background sprites.
