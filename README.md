# Dr. Karate — Browser Arcade

Браузерные приключения по Гравити Фолз: аркадная кампания, подземелья с кубиками и вестерн-пинбол «Террор перекати-поле». Диппер, Мэйбл и Рамбл, клавиатура и сенсорные кнопки. Также доступен быстрый бой до двух побед.

[Играть на GitHub Pages](https://andrk774.github.io/dr-karate-web/).

Это самостоятельная веб-адаптация, а не запуск движка M.U.G.E.N в браузере. Исходный комплект содержит сцены, но не персонажей; бойцы и боевая логика веб-версии созданы отдельно. Файлы в `1.0/`, `1.1/` и оригинальные ресурсы сохранены.

## Приключение

На главном экране выберите «Карта приключений», затем героя и доступный уровень. Персонажа можно менять между этапами. Все три героя используют одинаковые правила боя.

1. **Лес у Хижины Чудес** — знакомство с двойниками и первые страницы дневника.
2. **Улицы Гравити Фолз** — три последовательных боя на главной улице.
3. **Заброшенная шахта** — тоннель, кристаллы и усиленные противники.
4. **Додзё Доктора Карате** — бой с Доктором Карате открывает тропу к Хижине Чудес.
5. **Ночной лес** — лунная тропа со светлячками, три стража и подсказки о разломе.
6. **Разлом под Хижиной** — источник двойников, Страж разлома со 160 здоровья и закрытие портала.

Двигайтесь вправо: камера следует за героем, а выход становится доступен после победы над всеми противниками. На каждом этапе спрятаны три страницы. Страница восстанавливает 8 здоровья, победа над противником — 15. В начале нового этапа здоровье полное. Страницы необязательны для победы; уже пройденный уровень можно повторить, чтобы собрать все три.

После победы открывается следующий маршрут. Всего шесть уровней и 18 страниц. Выбранный герой, пройденные уровни и лучшее число страниц сохраняются в `localStorage` этого браузера (`dr-karate-campaign-v1`). Сохранения прежней кампании из четырёх уровней совместимы: пройденные этапы и страницы остаются, после додзё открывается «Ночной лес». Незавершённый этап при выходе на карту или перезагрузке начинается заново. Сохранение не синхронизируется между устройствами; при недоступном хранилище игра продолжает работать до закрытия страницы. Поражение не закрывает уже открытые уровни.

## Подземелья и кубики

Кнопка **«Подземелья и кубики»** находится под ареной. Выберите Диппера или Мэйбл и пройдите пять комнат: три боя (включая босса) и две развилки с ловушкой, сундуком или отдыхом. Ходы не ограничены временем. Монеты — итоговый счёт похода.

- Обычная атака: d20 + 4 против брони врага, урон d6 + 3. Натуральная 1 — промах, 20 — попадание с дополнительным кубиком урона.
- Защита: половина урона ответной атаки с округлением вверх; +4 к следующему попаданию с d20, без накопления бонуса.
- Диппер: «Секрет дневника», атака d20 + 8 и урон d8 + 4. Мэйбл: «Радужный залп», d6 + 3 урона без промаха и d6 + 4 лечения. На поход даётся три заряда.
- Зелье: d8 + 6 лечения. Враг отвечает после любого боевого действия, если ещё жив. Броня героя — 13, здоровье — 42.
- Отдых восстанавливает 12 здоровья и один заряд. Сундук даёт d6 × 10 монет и зелье. Ловушка проверяет d20 + 4 против 12: успех даёт 25 монет, неудача наносит d6 урона.

Журнал показывает все кубики и расчёты. После каждого действия поход сохраняется целиком в `dr-karate-dungeon-v1`, включая здоровье врага. Выход в меню и перезагрузка не теряют ход. После победы или поражения можно выбрать героя для нового похода. При заблокированном хранилище доступно продолжение до закрытия страницы.

## Террор перекати-поле

Отдельная фан-версия вестерн-пинбола по мотивам автомата **Tumbleweed Terror**. Выберите кнопку под ареной и запустите шарик. Цель — набрать **3000 очков** за три шарика и открыть выход.

- **A / ←** и **D / →** управляют флипперами; на телефоне удерживайте кнопки под полем.
- **Пробел** запускает шарик, когда поле в фокусе; **P / Escape** ставит игру на паузу. Центральная кнопка под полем запускает, приостанавливает и возобновляет игру.
- Перекати-поле даёт 50 очков, новая звезда — 150, уже горящая — 25. Три звезды дают дополнительный бонус 300, после чего набор звёзд сбрасывается.
- Потеря шарика расходует одну попытку. При выходе в меню или потере фокуса активная игра приостанавливается; продолжение вручную.

Рекорд сохраняется в `dr-karate-pinball-best-v1`. Текущая попытка живёт до перезагрузки страницы. Физика и графика стола реализованы в JavaScript/Canvas, дополнительные изображения не загружаются.

## Играть локально

Нужен Node.js 22 или новее. Сторонние зависимости не требуются.

```sh
npm start
```

Откройте <http://127.0.0.1:4173>. В PowerShell с запретом запуска `.ps1` используйте `npm.cmd start` либо `node scripts/serve.mjs`.

Альтернатива с Python: `python -m http.server 4173 --directory web`.

Запускайте через HTTP: двойной щелчок по `index.html` не подходит для загрузки ES-модулей и ресурсов.

## GitHub Pages

1. Создайте репозиторий с любым названием, например `dr-karate-web`, и загрузите этот проект, включая скрытую папку `.github`. Ветка — `main` или `master`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Publish Dr. Karate → Run workflow**. Следующие изменения в `main`/`master` публикуются автоматически.
4. После успешной публикации ссылка появится в **Settings → Pages** и в результате workflow. Адрес обычно имеет вид `https://<имя-пользователя>.github.io/<репозиторий>/`.

Workflow проверяет JavaScript, наличие всех кадров и правила боя, затем публикует только `web/`. Все URL относительные: игра работает и в подпапке репозитория. Инструкция основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Если используете готовый архив `dr-karate-web.zip`, распакуйте его и загрузите **содержимое** в корень репозитория. Архив включает `.github/workflows/pages.yml`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | A / D или ← / → |
| Прыжок | W, ↑ или пробел |
| Удар рукой | J |
| Удар ногой | K |
| Блок | удерживать L или Shift |
| Пауза / продолжить | P или Escape |

На телефоне доступны экранные кнопки с одновременными нажатиями. Звук включается кнопкой ♪. При потере фокуса бой ставится на паузу; продолжение — вручную. Блок уменьшает урон до 1, поэтому не защищает бесконечно. Побеждает первый, кто выиграл два раунда. При равном здоровье по таймеру назначается дополнительный раунд.

## Проверка и сборка

```sh
npm test
npm run check
npm run build
```

`build` копирует статическую игру в `dist/` для любого статического хостинга. GitHub Pages публикует `web/` напрямую, без сборки и без `npm install`.

Дополнительная браузерная проверка: при установленном Playwright и запущенном локальном сервере выполните `node tests/browser-smoke.mjs`. Проверяются бой, пауза, звук, смена сцены, потеря фокуса, сенсорное управление и ошибка загрузки. Скриншоты сохраняются в `.qa/`. Для тестирования подкаталога можно задать `GAME_URL`; если Playwright установлен вне проекта, задайте `PLAYWRIGHT_MODULE` с URL его модуля.

Кампанию проверяет `node tests/campaign-browser.mjs`: выбор героев, закрытые маршруты, все шесть побед, финал, 18 страниц, сохранение после перезагрузки, продолжение старого сохранения из четырёх уровней и мобильная версия. Для воспроизводимого теста маршрута противники остаются пассивными, но движение, столкновения, атаки, сбор страниц и обработчики победы выполняются реальным игровым кодом.

Новые режимы проверяет `node tests/extra-modes-browser.mjs`: полный поход с воспроизводимыми кубиками, продолжение после перезагрузки, оба героя, флипперы, пауза, победа и поражение в пинболе, рекорд, переходы между режимами и два одновременных касания. Проверка пинбольных экранов результата подставляет положение шарика у настоящих мишеней; отдельный модульный тест проходит весь стол естественным движением шарика и управлением флипперами.

- `web/engine.js` — правила боя, ИИ, раунды и физика.
- `web/campaign.js` — уровни, противники, прохождение и сохранение прогресса.
- `web/world.js` — панорамные фоны, страницы дневника и выходы.
- `web/dungeon.js`, `web/dungeon-ui.js` — комнаты, кубики, пошаговые бои, журнал и сохранение похода.
- `web/pinball.js`, `web/pinball-ui.js` — физика пинбола, стол, управление и рекорд.
- `web/game.js` — Canvas, анимации, ввод, звук и интерфейс.
- `web/fighters.js` — четыре спрайтовых персонажа, выбор поз и привязка к земле.
- `web/assets/fighters/` — четыре прозрачных спрайт-листа, по 12 поз на персонажа. Первые бойцы: [docs/fighter-art.md](docs/fighter-art.md). Новые герои, карта и панорамы: [docs/campaign-art.md](docs/campaign-art.md).
- `web/assets/` — 66 PNG-кадров, manifest и 2 MP3.
- `scripts/export_assets.py` — повторный экспорт из оригинального SFF v1. Требуется только стандартная библиотека Python 3: `python scripts/export_assets.py`.
- `tests/engine.test.mjs` — автоматические тесты боевых правил.
