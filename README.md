# Dr. Karate — Browser Arcade

Браузерный файтинг для одного игрока против компьютера. Оригинальные дневная и ночная сцены Dr. Karate, музыка, собственные бойцы, два уровня сложности, матч до двух побед, клавиатура и сенсорные кнопки.

Это самостоятельная веб-адаптация, а не запуск движка M.U.G.E.N в браузере. Исходный комплект содержит сцены, но не персонажей; бойцы и боевая логика веб-версии созданы отдельно. Файлы в `1.0/`, `1.1/` и оригинальные ресурсы сохранены.

## Играть локально

Нужен Node.js 22 или новее. Сторонние зависимости не требуются.

```sh
npm start
```

Откройте <http://127.0.0.1:4173>. В PowerShell с запретом запуска `.ps1` используйте `npm.cmd start` либо `node scripts/serve.mjs`.

Альтернатива с Python: `python -m http.server 4173 --directory web`.

Запускайте через HTTP: двойной щелчок по `index.html` не подходит для загрузки ES-модулей и ресурсов.

## GitHub Pages

1. Создайте репозиторий с любым названием, например `dr-karate-web`, и загрузите этот проект, включая скрытую папку `.github`. Ветка — `main` или `master`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Publish Dr. Karate → Run workflow**. Следующие изменения в `main`/`master` публикуются автоматически.
4. После успешной публикации ссылка появится в **Settings → Pages** и в результате workflow. Адрес обычно имеет вид `https://<имя-пользователя>.github.io/<репозиторий>/`.

Workflow проверяет JavaScript, наличие всех кадров и правила боя, затем публикует только `web/`. Все URL относительные: игра работает и в подпапке репозитория. Инструкция основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Если используете готовый архив `dr-karate-web.zip`, распакуйте его и загрузите **содержимое** в корень репозитория. Архив включает `.github/workflows/pages.yml`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | A / D или ← / → |
| Прыжок | W, ↑ или пробел |
| Удар рукой | J |
| Удар ногой | K |
| Блок | удерживать L или Shift |
| Пауза / продолжить | P или Escape |

На телефоне доступны экранные кнопки с одновременными нажатиями. Звук включается кнопкой ♪. При потере фокуса бой ставится на паузу; продолжение — вручную. Блок уменьшает урон до 1, поэтому не защищает бесконечно. Побеждает первый, кто выиграл два раунда. При равном здоровье по таймеру назначается дополнительный раунд.

## Проверка и сборка

```sh
npm test
npm run check
npm run build
```

`build` копирует статическую игру в `dist/` для любого статического хостинга. GitHub Pages публикует `web/` напрямую, без сборки и без `npm install`.

Дополнительная браузерная проверка: при установленном Playwright и запущенном локальном сервере выполните `node tests/browser-smoke.mjs`. Проверяются бой, пауза, звук, смена сцены, потеря фокуса, сенсорное управление и ошибка загрузки. Скриншоты сохраняются в `.qa/`. Для тестирования подкаталога можно задать `GAME_URL`; если Playwright установлен вне проекта, задайте `PLAYWRIGHT_MODULE` с URL его модуля.

- `web/engine.js` — правила боя, ИИ, раунды и физика.
- `web/game.js` — Canvas, анимации, ввод, звук и интерфейс.
- `web/assets/` — 66 PNG-кадров, manifest и 2 MP3.
- `scripts/export_assets.py` — повторный экспорт из оригинального SFF v1. Требуется только стандартная библиотека Python 3: `python scripts/export_assets.py`.
- `tests/engine.test.mjs` — автоматические тесты боевых правил.

## Авторы ресурсов

В `.def` авторы сцен указаны как **ScepterDPinoy & ShiroTori**. Графика извлечена из предоставленного `DrKarate.sff`, музыка скопирована из предоставленных `DrKarate1.mp3` и `DrKarate2.mp3`. Исходный комплект не содержит отдельной лицензии; этот проект не меняет права на эти ресурсы.
